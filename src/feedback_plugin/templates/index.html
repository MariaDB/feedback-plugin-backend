MariaDB Feedback Plugin Backend

This server collects the anonymous usage reports sent by MariaDB Server's feedback plugin and turns them into aggregate statistics.

Sending reports

Point the plugin at this server by setting feedback_url to {{ request.scheme }}://{{ request.get_host }}{% url 'post' %}. Reports are accepted as POST requests only.

Statistics

Aggregated data is available as JSON:

  • Server count
  • Version breakdown
  • Architecture breakdown
  • Feature count
  • Operating systems
